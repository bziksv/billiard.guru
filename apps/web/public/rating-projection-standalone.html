Проекция рейтинга

Формула tiny_upset_only (текущая). Для каждого игрока — средний ожидаемый рейтинг и коридор p10–p90 по Монте-Карло.

Данные встроены в файл (можно открыть offline / переслать).
Как считалось (не повтор старых турниров)
  • Исторические турниры не прогонялись снова. Из прошлого — текущие рейтинги и вес активности.
  • Независимые симуляции новых турниров с случайным составом и матчами.
  • Исход по логистике силы P = 1/(1+10^((Ropp−R)/1)), затем апдейт формулы.
